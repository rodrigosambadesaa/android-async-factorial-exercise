# Enunciado original — Factorial con tarea asíncrona

Fuente: proyecto `Ejercicio2AsyncTask` conservado en Google Drive.

Crear una aplicación Android que solicite un número entero y calcule su **factorial en segundo plano**, evitando bloquear el hilo principal mientras se realiza el cálculo y publicando el resultado en la interfaz al finalizar.

La solución original utilizaba `AsyncTask`, de acuerdo con el temario de 2018. La reimplementación conserva el objetivo y sustituye esa API obsoleta por un ejecutor de Java y publicación segura del resultado en el hilo principal.

No existe una base de datos asociada al ejercicio.
